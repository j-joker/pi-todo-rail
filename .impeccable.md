## Design Context

### Users
A developer collaborating with Pi during active terminal-based coding sessions. The rail is a shared control surface: the agent can plan and advance verified work, while the human can see, steer, complete, reopen, and override every step without leaving the coding flow.

### Brand Personality
Restrained, precise, and quietly polished. The interface should feel native to Pi rather than visually competing with it, with confidence coming from hierarchy, alignment, and interaction detail instead of decoration.

### Aesthetic Direction
Conceptual minimalism in the spirit of principled simplicity: reduce concepts, not just decoration. A todo is done or not; the current item is derived (first unfinished), and a blocker is a note. Compact English labels keep the extension language-neutral for its developer audience. ASCII markers keep roles distinct: `>` is the transient panel selection cursor, `*` is the persistent current todo, and `x` is done. Add/remove rows use Pi's diff foreground tokens with restrained success/error background bands; done rows use a success band while their task text stays dim. Progress remains secondary. Accent is reserved for focus, and neutral operations stay quiet. The panel exposes only selection, focus, and done/reopen—no decoration or secondary management surface.

### Design Principles
1. Remove concepts before removing pixels: derived state beats annotated state.
2. One plan, two operators: the agent advances verified work; the human retains visible, immediate control over the same state.
3. Keep interaction discoverable in one quiet key legend; anything more belongs in commands.
4. Plain text is the material: compact English, ASCII status markers, no decorative color or background bands. Symbols (`+`, `x`, `-`, `*`, `>`) carry all semantic weight.
5. Motion explains handoff, never decorates: a verified current item transitions through `x old` → `→ next` → `* next` in 200ms, without blocking input and with reduced-motion opt-out.
6. The interface should read like a correct program—nothing left to delete.
